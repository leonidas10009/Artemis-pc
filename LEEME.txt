ARTEMIS PC 2026 - 1.0.0

Cliente de escritorio para Apollo/Sunshine, basado en Moonlight Qt 6.2.0.

REQUISITOS
- Windows 10/11 de 64 bits.
- Apollo 2026 recomendado para pantalla virtual, portapapeles y comandos de energía.
- Permisos de ratón y teclado concedidos al cliente en Apollo (Web UI > Clients).

INSTALADOR (RECOMENDADO)
1. Ejecuta ArtemisSetup-1.0.0-win64.exe.
2. Sigue el asistente. Se instala en Program Files\Artemis 2026.
3. Abre Artemis desde el menú Inicio o el acceso directo.
4. Desinstala desde Configuración > Aplicaciones.
- El instalador no está firmado con un certificado comercial; SmartScreen puede avisar.

VERSIÓN PORTABLE
1. Extrae Artemis-1.0.0-win64.zip en una carpeta propia.
2. Ejecuta Artemis.exe.
3. Añade tu PC Apollo y empareja el cliente.
4. Introduce el PIN en la Web UI de Apollo.

CONFIGURACIÓN
- Portable: la configuración se guarda en "Artemis 2026 Project\Artemis.ini".
- El modo portable se activa con el archivo portable.dat.
- Instalador: la configuración se guarda en el perfil del usuario.

TECLADO Y RATÓN
- Ctrl+Alt+Shift+Z: liberar o recapturar ratón y teclado.
- Ctrl+Alt+Shift+M: alternar modo ratón para juegos / escritorio remoto.
- Ctrl+Alt+Shift+K: activar o desactivar la captura de atajos del sistema.
- Si no llega la entrada, revisa los permisos del cliente en Apollo > Clients.

TEMAS
- Botón de paleta en la esquina superior derecha.
- Ctrl+T: siguiente tema.
- Ctrl+Shift+T: abrir el selector de temas.
- También disponible en Ajustes > UI.
